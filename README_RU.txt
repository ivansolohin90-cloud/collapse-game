Коллапс 1.3.5 — режим MODE

Загрузите файлы из этой папки в корень GitHub Pages, заменив одноимённые файлы.
Режим MODE выбирается в меню «Режим». Внизу игрового поля доступны четыре способности:
⚀ обычное повышение (взрыв на 4), ⚄ усиление (взрыв при повышении 5 до 6), 1 понижение своей фишки 3–5 уровня до 1, 🚫 удаление своей фишки.
За ход выполняется одно действие. Выбранная способность сохраняется между ходами.
Сохранения хранятся локально в браузере на устройстве.
