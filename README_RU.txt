КОЛЛАПС — PWA версия

Загрузить в корень GitHub-репозитория все файлы из этого архива:
- index.html (заменить старый)
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

После загрузки дождаться обновления GitHub Pages и открыть:
https://ivansolohin90-cloud.github.io/collapse-game/

Затем открыть игру в Chrome, дождаться полной загрузки и нажать кнопку
«Установить Коллапс» внутри игры. Если Chrome не показывает системное окно,
использовать меню Chrome ⋮ → «Установить приложение» / «Добавить на главный экран».

Офлайн:
После первого успешного открытия сайта при подключённом интернете Service Worker
сохранит оболочку игры и иконки. После этого установленное приложение сможет
открываться без интернета.

Обновления:
Для следующей версии заменить файлы в том же репозитории. При каждом выпуске
изменять CACHE_NAME в sw.js (например, collapse-app-v3), чтобы браузер забрал
новую версию из сети. Ссылка GitHub Pages останется прежней.

Важно:
Этот пакет сохраняет текущую игровую механику из присланного index.html.
Сохранение состояния текущей партии между закрытиями приложения в эту версию
пока не добавлено.
