Коллапс 1.3 — обновление

В архиве шесть файлов. Загрузите ВСЕ файлы в корень GitHub-репозитория, заменив старые файлы с совпадающими именами:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- README_RU.txt (необязательно, только инструкция)

Новое в версии 1.3:
- автоматическое сохранение незавершённых партий в памяти браузера/приложения (до 5 партий);
- меню «Партии»: продолжить или удалить сохранённую партию;
- завершённые партии удаляются из списка сохранений после победы;
- пошаговая анимация цепной реакции;
- размеры поля 21×28, 50×70 и 100×120;
- камера автоматически центрируется на игроке, чей сейчас ход.

Важно:
- Сохранения хранятся на этом устройстве в данных браузера (localStorage). Очистка данных сайта/браузера может удалить их. Они не синхронизируются между устройствами.
- Сохранение обновляется автоматически после ходов. Чтобы продолжить, откройте «Партии» и нажмите «Продолжить».
- До 5 сохранений одновременно; можно удалить ненужные вручную.

После загрузки файлов:
1. Откройте сайт GitHub Pages и обновите страницу.
2. Если старая версия продолжает показываться, полностью закройте приложение и откройте снова, затем обновите страницу при подключённом интернете.
3. Новая версия service worker использует кэш collapse-app-v3.
