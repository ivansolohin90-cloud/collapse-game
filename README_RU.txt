КОЛЛАПС — обновление 1.3.6

В архиве: index.html, manifest.webmanifest, sw.js и две иконки.

Как обновить GitHub Pages:
1. Распакуй архив.
2. В репозитории GitHub открой Upload files.
3. Загрузи ВСЕ файлы из этой папки в корень репозитория.
4. Подтверди изменения (Commit changes).

Важно: новая версия хранит до 10 партий. Новые партии не заменяют старые.
Если список заполнен, игра не начнёт новую партию, пока одну из сохранённых не удалить.
Завершённые партии остаются в списке как завершённые и их можно удалить вручную.

Партии хранятся в памяти браузера на этом устройстве и в этом профиле Chrome.
Не очищай данные сайта/браузера и не переустанавливай приложение, если хочешь сохранить партии.
